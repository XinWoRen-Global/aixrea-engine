## Skill / Tool Developer Revenue

### Integrated with CreatorTier (no separate system)

Tool developers are **creators** on the platform. Their skill revenue follows the existing **CreatorTier** system, the same as drama/music/comic creators:

| Creator Tier | Revenue Share | How to Level Up |
|---|---|---|
| **Bronze** | 50% | Default on signup |
| **Silver** | 60% | Monthly publish volume + engagement |
| **Gold** | 70% | Top creators, verified quality |
| **Platinum** | 70% + bonus | Invitation-only, strategic partners |

> This is the **same system** used by all content creators on the platform. No separate commission tier for tool developers. A user can be both a tool developer AND a content creator AND an affiliate — all under one account.

### Payout Terms

- **Minimum payout**: $10 (accumulated)
- **Frequency**: Monthly (net-30)
- **Method**: Stripe / PayPal / bank transfer
- **Currency**: USD

### Developer Eligibility

- Open to all registered creators
- Skills must pass automated security review
- No exclusivity required (publish anywhere)
- You retain ownership of your skill code

## Outstanding Contributions

We do **not** offer permanent revenue share (dividends). Instead:

| Recognition | Reward | Cost |
|---|---|---|
| **Platinum Creator Tier** | 70% revenue share + platform features | Zero (existing system) |
| **Annual Best Tool / Best Creator** | One-time cash bonus + coins | Low (awarded from revenue) |
| **Strategic contribution** | Equity / options (post-funding) | Case-by-case |
| **Top contributor hire** | Full-time role | Case-by-case |

> Industry practice: Google GDE, Microsoft MVP, AWS Hero all use "certification + benefits" without permanent dividends. Shopify and Salesforce use tiered revenue share. Permanent dividends create liability that complicates future fundraising.
