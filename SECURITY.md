# Security Policy

## Supported Versions

Aixrea Engine follows a rolling release model. Please use the latest tagged release to receive security updates.

| Version | Supported |
|---------|-----------|
| v0.1.x  | ✅        |
| main    | ✅ (development) |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately:

- **Email**: contact@xinworen.com
- **GitHub**: https://github.com/XinWoRen-Global/aixrea-engine/security/advisories

We aim to respond within 48 hours and will keep you informed throughout the resolution process.

Please **do not** open public issues for security vulnerabilities.
