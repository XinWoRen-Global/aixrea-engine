## Что такое Aixrea Engine?

Aixrea Engine — это open-source **супер-harness для агентов**, который оркестрирует **субагентов**, **память** и **песочницы** для создания производственных AI-приложений. Он обеспечивает гибкую и расширяемую основу для:

- 🤖 **Оркестрации мультиагентных систем** — Lead Agent координирует специализированных субагентов
- 🧠 **Персистентной памяти** — краткосрочная, долгосрочная и сводная память
- 🛠️ **Расширяемых навыков** — создавайте и публикуйте AI-инструменты как повторно используемые навыки
- 🔄 **DAG-пайплайнов** — детерминированное выполнение рабочих процессов для создания контента
- 🔒 **Контроля контента** — подключаемый фреймворк модерации AI-вывода
- 💬 **Сообщества** — чат в реальном времени с AI-сотрудниками

Построено на **LangGraph** для надёжных и восстанавливаемых рабочих процессов агентов.

## Архитектура

```
┌─────────────────────────────────────────────────┐
│                   Lead Agent                      │
│  (Гибрид Plan-and-Execute + ReAct, 15+ middleware)│
├──────────┬──────────┬───────────┬────────────────┤
│  Память   │  Навыки  │  Песочница │  Субагенты    │
│  (кратко/ │  (рынок  │  (выполнение│  (специалисты)│
│   долго/   │  инструментов)│ кода) │                │
│   сводка)  │          │            │                │
├──────────┴──────────┴───────────┴────────────────┤
│              PipelineExecutor (DAG)                │
│     (детерминированные процессы создания контента) │
├────────────────────────────────────────────────────┤
│              AIGateway (маршрутизация моделей)      │
│     (абстракция мультимодельности, откат, трекинг) │
└────────────────────────────────────────────────────┘
```

### Трёхуровневая модель управления

| Уровень | Паттерн | Сценарий использования |
|---|---|---|
| **Граф рабочего процесса** | DAG (детерминированный) | Основная цепочка выполнения, биллинг, восстановление |
| **Plan-and-Execute** | Декомпозиция задач | Сложные многошаговые задачи |
| **ReAct** | Локальное исследование | Неизвестные среды, обнаружение инструментов |

## Быстрый старт

### Предварительные требования

- Python 3.12+
- Node.js 22+ (для фронтенда/инструментов)
- Redis (для памяти/кэша)
- API-ключ LLM (OpenAI, Anthropic или совместимый)

### Установка

```bash
# Клонировать
git clone https://github.com/XinWoRen-Global/aixrea-engine.git
cd aixrea-engine

# Установить зависимости бэкенда
cd backend
pip install -e .

# Настроить
cp .env.example .env
# Отредактируйте .env, указав API-ключи LLM

# Запустить
uvicorn app.main:app --reload --port 8001
```

### Минимальный пример

```python
from aixrea_engine import LeadAgent, SkillRegistry

# Инициализация
agent = LeadAgent(
    model="gpt-4o",
    skills=SkillRegistry.default(),
    memory=True,
)

# Запуск
result = await agent.run("Исследуйте топ-3 AI-фреймворка в 2026 году")
print(result.summary)
```

Больше примеров в [`examples/`](./examples).

### Доходность Marketplace

Разработчики инструментов — это **создатели** на платформе. Доход от навыков следует существующей системе **CreatorTier** (так же, как у создателей драмы/музыки/комиксов):

| Уровень создателя | Доля разработчика | Платформа |
|---|---|---|
| Bronze | 50% | 50% |
| Silver | 60% | 40% |
| Gold / Platinum | 70% | 30% |

- **Без отдельной комиссионной системы** — один аккаунт, один уровень, все типы доходов унифицированы
- **Выплаты** : Ежемесячно через Stripe, минимум 10 $
- **Без эксклюзивности** : Публикуйте свои навыки где угодно
- **Вы сохраняете право собственности** на код своих навыков

Партнёрские рефералы следуют существующей партнёрской программе (до 25%, cookie 30 дней).
