# Contributing to Aixrea Engine

Thank you for your interest in Aixrea Engine!

## Current Status: Read-Only Open Source

Aixrea Engine is currently released as **read-only open source**. This means:

- The source code is available for learning, research, and internal use
- We are **not accepting external pull requests** at this time
- Issues and feedback are welcome, but response times may vary

## Why Read-Only?

Aixrea Engine is the core framework powering XinWoRen / Aixrea's production platform. We open-source it to contribute to the AI agent community and enable transparency, while maintaining tight control over the roadmap and quality.

## Ways to Contribute

While we don't accept code PRs, you can contribute by:

1. **Reporting bugs** — Open an issue with clear reproduction steps
2. **Suggesting features** — Open an issue describing your use case
3. **Documentation improvements** — Open an issue, and we'll update the docs
4. **Building extensions** — Use our Skill SDK to build tools and share them in our marketplace
